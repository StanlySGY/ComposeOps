# 界面主题

“设置 → 个人偏好 → 界面主题”可选深色、浅色、跟随系统。默认保持深色。

选择即时生效，保存到当前浏览器的 `composeops:theme`，并同步同源标签页。系统模式响应操作系统变化；浏览器禁止存储时，当前会话仍可切换。首屏通过独立 `theme-init.js` 提前设置主题，兼容默认 CSP。

浅色使用白色面板、深色文字和冷灰背景。终端 ANSI 色板与 Monaco 配置编辑器随主题变化，终端无需重连。拓扑、图表、AI Markdown 和常用弹层采用主题颜色变量；PNG 导出冻结当前实际配色。

状态逻辑见 `frontend/src/lib/theme.js`，主题变量见 `frontend/src/theme.css`。测试覆盖默认值、系统变化、跨标签同步、存储受限、首屏一致性、主题选择和终端色板。
