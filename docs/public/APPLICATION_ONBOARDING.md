# 应用接入向导

“应用可靠性 → 接入向导”提供选择应用、健康目标、业务恢复、告警通知、修复权限和审阅提交六个步骤。只支持已纳管应用，显示已配置、待配置与不支持原因。

可以关联已有健康目标和恢复计划，也可新建；不支持业务恢复时必须记录待办原因。告警默认采用联合短长窗口；外部通知使用已有全局通知渠道，尚未配置时可先仅在面板显示，并继续在通知设置页配置。

自动修复默认关闭，启用需填写有效天数、每日上限和冷却时间，并在最终审阅中单独确认。它最后才写入，前面配置失败不会提前开启修复。接入完成不会立即创建业务备份或恢复生产数据；只有显式启用的定时计划会按间隔执行备份与隔离演练。

草稿持久保存在数据库，创建请求有幂等标识，提交按项目串行。健康目标与业务计划使用固定创建 ID，进程在创建后、记录进度前中断时可重新查回。已完成步骤保持版本，不因重复提交产生新配置；外部修改会阻止旧草稿覆盖。部分失败保留进度、错误和待完成步骤，可重新审阅后恢复。

接入配置已提交不等于所有能力均已验收。稍后配置的灾备或通知仍标注待配置；后续分别到应用目标、业务恢复、可靠性告警和通知设置中编辑。已开启的自治授权可在应用目标页停止。
