# Release Checklist

每次稳定版发布均重新核验；未勾选项不表示已经验证。

## 自动门禁

- [ ] 版本、锁文件、CHANGELOG 与安装清单一致
- [ ] 后端串行测试、前端测试与 lint 通过
- [ ] 正式应用与静态预览构建通过
- [ ] 预览桌面/移动浏览器交互与资源子路径通过
- [ ] 镜像首次安装、认证与重启持久化通过
- [ ] 从支持基线 1.4.0 升级通过
- [ ] 在线 SQLite 快照恢复到新卷后可登录并读取配置
- [ ] Agent 工具风险登记完整；新工具缺少风险元数据时测试应失败
- [ ] 嵌套 JSON、自由文本、历史记录、执行审计与 MCP 输出的秘密脱敏回归通过
- [ ] SSH 主机指纹接受正确值并拒绝错误值的本地隔离测试通过
- [ ] 通知 5xx/网络故障有界重试与 4xx 不重试测试通过
- [ ] Agent SSE 慢客户端背压限制与取消清理测试通过
- [ ] SQLite 静态加密迁移、错误密钥拒绝、加密备份恢复与密钥轮换测试通过
- [ ] Redis/PostgreSQL 真实隔离容器健康探测、停止/恢复与数据持久化验收通过
- [ ] 本机真实 HTTP Webhook 接收 JSON 并验证 503 重试通过
- [ ] 隔离 Docker 命名卷备份/还原与 SHA-256 内容核验通过
- [ ] amd64/arm64 镜像发布成功后创建 GitHub Release

以上由 Quality checks / Release 执行，以对应 Actions run 为证据。

## 人工复核

- [ ] 文档链接、安装命令和备份恢复步骤
- [ ] 提交中无真实凭据或用户数据库
- [ ] 桌面和手机视觉复核
- [ ] GitHub Pages 公网可访问，明确标注示例数据

## 尚需扩展的验证

- [ ] Redis/PostgreSQL 的外部模型驱动根因分析与经用户审批的真实修复闭环（需要模型渠道）
- [ ] SSH/TLS 多节点真实部署故障矩阵、真实证书轮换与 WAN 断线恢复
- [ ] 通知渠道真实送达（需要第三方渠道凭据/测试端点）
- [ ] 数小时级运行的内存/CPU/文件描述符 soak test
- [ ] 生产密钥托管、异地加密备份恢复演练与灾难恢复耗时验收

本地假服务测试不等于第三方服务送达或生产环境验收；静态预览和本地镜像冒烟测试同样不能替代上述项目。
