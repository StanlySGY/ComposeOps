# 应用访问入口

服务卡片按 Compose 服务展示候选网页入口，容器行显示宿主端口、容器端口及协议。IPv4 / IPv6 重复映射合并，UDP 和常见数据库端口不生成网页链接；其余 TCP 候选端口全部保留。容器目标端口为 443 时使用 HTTPS。远程节点使用该节点地址，本地节点使用面板请求的主机名，IPv6 保留方括号。

主机网络优先读取 EXPOSE；没有 TCP 声明时，仅识别 `WEB_PORT`、`WEBUI_PORT`、`WEB_UI_PORT`、`HTTP_PORT`、`HTTPS_PORT`。界面标明声明或配置来源，不向列表返回环境变量正文。候选链接不代表已经验证 HTTP 连通性。

入口旁的设置按钮及项目更多操作中的“访问入口”可设置 `/web/` 等路径。留空或 `/` 恢复根地址。只改变面板链接，不修改应用配置或重启容器。路径禁止外部域名、查询参数、控制字符及跳转路径。

配置按节点、项目、Compose 服务名与宿主端口保存，容器重建后保留。保存采用版本检查；节点切换关闭旧弹窗，冲突返回 409。数据库迁移 v30 创建独立配置表，响应禁止缓存，操作日志不记录路径内容。

项目纳管和目录权限保持现有规则；此功能不自动纳管项目，也不添加独立的账号密码管理库。
