# Public Roadmap

## 1.5.0 的交付范围

- 多渠道故障切换、单渠道保存、密钥按需查看与工具兼容性测试。
- 可重新打开的入门指南、可折叠导航与离线交互预览。
- 发布前必须通过代码检查、浏览器预览检查与隔离镜像安装/升级/恢复检查。
- SQLite 在线一致性备份；应用数据卷仍需按数据库类型制定备份策略。

## 下一步，以证据验收

- SSH/TLS 多节点实环境矩阵：断线、重连、证书错误与节点切换隔离。
- 通知渠道端到端送达与失败重试测试。
- 长时间日志流、Agent 会话和后台任务的资源占用回归。
- 更广泛的上游模型兼容性矩阵，记录模型版本、流式与工具调用结果。
- 数据库案例的独立环境演练与恢复耗时记录。
- 英文 UI 与键盘/读屏可访问性审计。

## 验证边界

静态预览是交互演示，不能证明真实 AI 修复能力。镜像检查覆盖本地 Docker 的应用配置持久化与 SQLite 恢复，不等于远端主机、所有业务数据库和跨大版本升级已验证。当前仍是单管理员工具，不承诺多租户隔离或零停机升级。
