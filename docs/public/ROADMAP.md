# Public Roadmap

## 1.5.0 的交付范围

- 多渠道故障切换、单渠道保存、密钥按需查看与工具兼容性测试。
- 可重新打开的入门指南、可折叠导航与离线交互预览。
- 发布前必须通过代码检查、浏览器预览检查与隔离镜像安装/升级/恢复检查。
- SQLite 在线一致性备份；应用数据卷仍需按数据库类型制定备份策略。

## 已完成的安全与可靠性改进

- SSH 远程运维支持可选 SHA-256 主机指纹锁定；错误指纹在握手阶段被拒绝。旧节点未配置指纹时为兼容现有部署仍允许连接，建议通过可信渠道核对后补齐。
- Webhook 类通知遇到网络瞬断、限流或服务端 5xx 时进行有界重试；鉴权及其他非重试型 4xx 立即失败，避免无意义重试。
- 本地自动化测试覆盖 SSH 主机指纹验证、TLS CA/客户端证书和多节点故障隔离、通知重试与本机真实 HTTP Webhook 投递、Agent SSE 取消/慢客户端背压、后台任务内存上限、Docker 隔离卷恢复和 SHA-256 内容核验。
- SQLite 静态加密采用独立只读密钥文件；明文迁移先流式复制到加密临时文件，并在原子替换前核对完整性、迁移版本、关键表行数与外键检查结果。加密备份已恢复到全新数据卷，停机密钥轮换也已验证新密钥成功、旧密钥拒绝。
- 当前本机运行实例已启用数据库静态加密；重启后健康检查通过，schema 版本与迁移前关键表行数一致。保留了权限受限的独立加密前快照作回退依据。新装默认仍兼容明文安装，加密启用步骤见《SQLite 数据库静态加密》。

## 下一步，以证据验收

- 生产密钥的异地独立保管与恢复演练；已新增 `npm run recovery:drill`，会将加密备份恢复到一次性临时位置，核验外置密钥、完整性、schema、迁移版本与核心表行数。本机现有 345,853,952 字节的加密快照已于 2026-10-14 和 2026-10-15 两次通过演练；最新报告显示恢复字节数完全一致、`integrity_check=ok`、schema 版本 16、55 个 schema 对象和核心表计数匹配，在线数据库未修改且报告未记录密钥内容。当前验证仍发生在同一主机，独立 KMS/异地保管、另一主机恢复与灾难恢复时间目标尚未验收。
- 真实远程多主机 SSH/TLS 部署矩阵：节点证书签发/轮换、真实 WAN 断线/重连、服务端证书更新与不同权限账号；本地多节点假服务验证不替代实际部署验收。
- 第三方通知渠道实际送达及平台限流策略：本地 HTTP Webhook 已测试请求体与 503 重试，但尚未用生产渠道凭据验证外部平台最终收件。
- 数小时级持续 Agent 会话/日志跟随/SSE 的 CPU、内存、FD 与慢消费者 soak test；已新增 `scripts/agent-soak.mjs`，可用独立临时数据库和模拟模型持续施压，并采集 RSS/堆/外部内存、CPU、FD、事件循环延迟，覆盖慢读与客户端断开清理。2026-10-15 的 60 秒本地短时压力检查通过：请求错误 0、RSS 峰值增长 0.8 MiB、FD 峰值增长 1、平均 CPU 7.4%、采样事件循环 p95 最大值 20.7 ms，结束时活动执行与待审批均为 0；正式 4 小时验收仍需运行 `npm run test:agent-soak -- --duration-seconds=14400 --report-file=soak-report.json` 并归档 JSON 报告。
- 真实模型驱动的 Redis/PostgreSQL 根因分析与修复演练：本地自动化已调用真实容器的固定只读健康工具，验证停止、恢复与数据持久化；尚未将实际外部模型接入并执行经过审批的修复链路。
- 可访问性审计持续推进：移动端“更多功能”抽屉、顶部 Docker 节点/项目切换器、事件中心、通用 BaseModal 及资源监控告警配置弹窗已补齐模态语义和关联标签；支持初始聚焦、Tab/Shift+Tab 焦点循环、Esc/遮罩/关闭按钮关闭后恢复焦点。修复嵌套弹窗误将焦点定位到父弹窗的问题，并将事件中心所有关闭路径统一清理实时事件流。资源告警表单的三项输入现在均与可见标签关联。项目环境变量、日志、项目卡片、资产、任务、模板、资源监控、拓扑和工作流等图标按钮已补齐 aria-label；静态扫描未发现未命名的纯图标按钮候选项。新增组件和浏览器回归；本轮全量单元测试 38 个文件、282 项全部通过，Vue/Router 注入警告为 0。模板变量弹窗补齐每个动态字段的唯一 ID、label/输入框关联与说明文本 `aria-describedby`，新增必填校验和字段关联回归测试；通用 BaseModal 修复焦点落在对话框容器时 Shift+Tab 可能离开弹窗的问题，并增加双向焦点循环回归测试。最新全量本地验证为 40 个测试文件、287 项全部通过，Lint、正式构建、预览构建与浏览器检查通过（23 通过、1 项既有预期跳过）；环境变量编辑器的动态 Key/Value/注释输入、搜索框、原始文本和环境文件选择器补齐明确可访问名称，并增加组件回归测试。AI 一键诊断弹窗的流式进行中/完成状态现在通过 polite live region 原子播报，错误使用 assertive alert 播报，并增加状态迁移回归测试。Docker Run 转换器补齐命令输入的 label 关联、输出区域名称、复制/下载图标按钮名称，以及错误与复制成功的屏幕阅读器播报，并增加组件回归测试。Agent 日志上下文选择器补齐项目/容器/搜索控件名称、加载/错误播报和旧请求防覆盖逻辑；操作输出抽屉补齐批量进度语义、任务完成数播报及终端输出区域名称。实时日志页面补齐筛选器名称、连接状态播报、错误提示语义，以及聚合/容器按钮的按下状态。上述组件新增回归测试；容器终端启用 xterm 屏幕阅读器模式，终端区域有动态可访问名称，连接状态以 polite live region 播报，连接错误以 alert 呈现。设置页面的偏好、密码、检索、通知与镜像检查表单补齐明确可访问名称；全局保存反馈统一使用 polite status，错误使用 alert；缺少 Webhook/第三方通知地址时给出可理解的字段错误，而不再显示空错误。AI 渠道编辑器将保存/排序失败通过 assertive alert 播报，成功反馈保留 polite status，新增渠道表单和错误播报回归测试。数据卷备份面板新增项目/筛选控件可访问名称、加载失败与批量备份结果播报；失败不再被伪装为“没有卷/没有备份”，并防止旧项目的迟到请求覆盖当前列表。Docker 存储清理面板补齐磁盘分布图文本等价、加载/错误/释放空间状态语义；读取失败不再无限停留在加载提示。两个高风险组件新增 6 项回归测试。最近一次完整全仓库 npm test 为后端与前端测试均通过，前端 50 个测试文件、313 项通过；Lint、正式构建、预览构建及 Playwright 浏览器回归（23 通过、1 项既有预期跳过）通过。其余页面的完整读屏语义、键盘导航及英文 UI 仍需系统性复核。更广泛的上游模型兼容性矩阵仍未验收。

## 验证边界

静态预览是交互演示，不能证明真实 AI 修复能力。自动化验收包含实际本机 Redis/PostgreSQL 容器、HTTPS/TLS 与 loopback Webhook，但不等于真实远端主机、第三方平台送达、外部模型驱动修复、所有业务数据库或跨大版本升级已全部验收。当前仍是单管理员工具，不承诺多租户隔离或零停机升级。
