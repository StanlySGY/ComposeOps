# 在线预览的范围

[打开预览](https://stanlysgy.github.io/ComposeOps/)。预览直接加载正式版的 `App.vue`、路由、页面组件和 `style.css`，使用同一套顶部工具栏、导航、表单、弹层与移动端布局。顶部只增加预览说明和安装入口，不再单独设计一套简化产品页面。

## 数据与操作

- 所有项目、日志、指标、模型渠道和密钥均为虚构示例。
- 服务搜索、配置编辑、日志筛选、多渠道编辑、显隐示例密钥和排序使用真实前端逻辑。
- AI 回复为明确标注的预设流程，通过真实审批组件演示拒绝与确认；不是在线模型推理。
- 已模拟的写操作只改变当前浏览器页面内存，刷新后重置。不会访问 Docker、模型渠道或真实 API。
- 配置编辑器在预览中不下载外部 Schema，校验仅检查 YAML 语法；Docker 语义校验需要真实部署。
- 未模拟的操作明确提示不可用，不返回虚假的成功结果。高级页面可能展示空态，这不代表正式部署没有该功能。

## 维护约束

预览入口位于 `frontend/preview/`。`transport.js` 在导入正式应用前安装离线 fetch / WebSocket；没有原生网络回退。CSP 禁止连接后端，使用独立静态构建，正式部署不加载此适配器。

不要向 fixtures 导入真实实例数据、API Key 或数据库导出。不要复制页面组件或另写预览专用的产品布局，以免再次与正式界面分离。

## 验证

```bash
npm --prefix frontend run build:preview
npm --prefix frontend run test:preview
npm --prefix frontend run preview:serve
```

浏览器测试覆盖桌面/移动端真实路由、页面渲染、网络隔离、AI 审批拒绝/确认、渠道保存/密钥显示/排序、服务搜索、日志与卷备份演练。CI 成功后，Pages 发布同一次 CI 的预览构建产物。
