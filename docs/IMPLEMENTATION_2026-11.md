## 批次 1：B-01～B-08

- B-01：v20 固定旧项目 ID 的宿主归属（升级时活动节点；未配置则 local），该节点保留原 ID，其它节点增加命名空间。同路径同名项目的偏好、配置备份和历史引用不重写、不丢失。旧库本就无法分辨的历史跨节点记录不会被猜测性重新分配。
- B-02：各已配置节点独立采集指标、维护 Docker 事件流、评估健康/资源告警和镜像更新。监控页支持当前/全部/指定节点，事件状态历史标注与筛选节点；历史指标压缩和可用率计算按节点隔离。
- B-03：数据库 dump 按 Docker frame 有界解码，先写私有临时文件，等待落盘、零退出码、非空及完整 gunzip 校验，再原子发布。后台不创建下载流；请求中断、超时或校验失败删除临时文件并记录失败告警。
- B-04：扫描结果仅含 hostId/hostName，不含连接凭据；Compose、workspace、容器控制、日志、卷备份和镜像操作固定目标客户端。前台操作切节点时拒绝后续写入；本地子进程终止，workspace 断流并报错。已提交给 Docker 的单次请求无法撤销，但不会改向其它节点。
- B-05：进程内重入队列外增加 SQLite TTL lease（120 秒租期、30 秒续约），跨进程冲突明确返回 409；cron pull 共用项目执行器。
- B-06：旧 cron JSON 首次成功读取后迁入 SQLite；损坏时拒绝覆盖并告警。定义和历史随数据库备份，个人数据导出包含 cron。
- B-07：Compose config 校验 30 秒硬超时，终止子进程后释放项目锁。
- B-08：`/health` 报告面板自身存活和逐节点 `{id,ok,latencyMs}`，远端失联不会让面板返回 503。

### 数据演练

```sh
node backend/scripts/host-identity-migration-drill.js --backup=/外部目录/独立备份.db
```
