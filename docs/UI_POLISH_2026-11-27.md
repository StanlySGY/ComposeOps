# 界面与交互打磨验收 · 2026-11-27

本轮基于 `feat/fork-improvements-20261126`，集中改善完整备份页，并修复走查发现的总览浅色主题可读性问题。

## 改动

- 备份记录优先展示，保存目录与恢复密钥合并为可展开设置；新增选择应用入口。
- 备份卡片区分文件校验状态、保存位置与恢复操作；同步不可用时提供配置目标入口。
- 隔离恢复按选择目录、核对映射、确认恢复展示。长路径按源位置和目标位置对照，窄屏纵向排列；弹窗内容独立滚动，操作区保持可见。
- 预览期间显示等待反馈；修改目录后立即废弃映射、启动选项与确认状态，提示重新校验。空白目录不能提交，阻断计划不能勾选或执行。
- 筛选明确显示隐藏选择的数量与作用范围，支持清空选择；页签使用单一 Tab 停靠点和方向键导航。
- 复用现有恢复插画和公共空状态组件，补齐备份、同步、任务与搜索的下一步引导。没有新生成或引入图片资源。
- 首次加载使用骨架屏；后台轮询保留已显示的空状态，避免每五秒隐藏入口并造成布局跳动。
- 总览概览卡及项目入口的背景随深浅主题变化，修复浅色主题下深色背景叠加深色文字的问题。
