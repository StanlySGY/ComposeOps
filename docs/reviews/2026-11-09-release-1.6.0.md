# v1.6.0 发布收尾

本轮处理发布成熟度复核中的三个具体问题：公开稳定版滞后于当前产品、发布文档互相矛盾、缺少从当前公开稳定版 1.5.1 升级和回退的明确门禁。

## 变更

- 根目录与两个 workspace、根 lockfile、安装清单和中英文 README 统一为 1.6.0；CHANGELOG 整理 1.5.1 之后的功能与修复。版本检查新增根 lockfile 和两份 README 安装链接校验；Release 正文内的文档链接指向固定 tag。
- 更正 Cookie 默认 SameSite=Lax、HTTPS Secure 与显式嵌入模式说明；补齐默认明文/可选加密边界。历史验收清单独立归档，当前清单明确原生 ARM64、隔离与生产、真实渠道与受控测试的区别。
- 增加升级/回退指南，要求配对旧镜像和升级前快照，保留原卷、项目名、端口与外置密钥。
- 镜像冒烟新增升级前在线快照、旧版在独立新卷恢复、鉴权与配置保留；首次安装路径新增明文到加密迁移、加密备份、明文标记检查和外置密钥恢复。amd64 继续覆盖 1.4.0，并与原生 ARM64 一起新增 1.5.1 升级/回退。
- Release 复用质量门导出的两个已验收镜像，发布前逐一检查镜像 ID、架构和提交 SHA，不在验收后重新构建；双架构上传完成后才更新正式 manifest 和创建 Release。

## 本地证据与发布门

基于 56faa91 产品代码的本地 1.6.0 镜像已通过首次安装、密码鉴权、重启持久化、在线快照/新卷恢复、明文到加密迁移和加密恢复。1.5.1 升级后原密码与配置保留，升级前快照能在另一新卷运行旧版。真实隔离 Redis/PostgreSQL 与命名卷恢复集成通过。所有测试只操作带随机前缀的临时容器/卷，结束后清理。

Lint 零错误，保留既有测试夹具的三条 warning；版本元数据和 YAML 语法检查通过。双架构完整结果以 v1.6.0 tag 的 Release 工作流为准；此记录不提前声称远程发布成功。产品视觉与交互沿用 [上一轮验收](2026-11-09-image25-experience.md)。
