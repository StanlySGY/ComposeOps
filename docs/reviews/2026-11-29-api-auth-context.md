# 普通 API 响应的会话归属

日期：2026-11-29；基线 a5ead70。

## 已确认的问题

前一轮修正了身份状态请求，但普通业务 API 的迟到 401 仍会无条件广播会话失效。重新登录或修改密码换发 Cookie 后，旧请求因此可以清掉新身份。旧成功响应仍交给原调用方，认证失效时的内存缓存也没有独立的会话隔离；旧 GET 遇到网络故障可能带新 Cookie 自动重试。

## 修复

普通 API 请求固定发起时的前端会话代次；登录、退出、失效和成功修改密码推进代次。读取响应头、响应体以及重试前检查归属，旧响应不交付、不广播失效或成功、不重新请求。当前会话的 401 继续正常清理身份。下一次请求发现代次变化时清空缓存，旧结果不能写回。

这是前端响应归属管理，不替代后端鉴权，也不能撤销已提交的服务端动作。旧写操作结果不自动重放，错误明确要求核对结果。既有流式请求仍按各页面的 AbortSignal 与生命周期管理，本轮没有把普通请求修复夸大为全部流协议重写。
