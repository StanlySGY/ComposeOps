## 新增能力

`scripts/release-retention.mjs` 在宿主维护成功发布的数据库副本：

- 默认只预览，清单 0600、一小时有效，显示候选、保留项、原因和字节数。
- 默认保留最近两份及七天内备份，可增加保留数，不能少于两份；.retain 固定保留，.deploying 阻止清理。
- 只处理匹配成功发布凭据的 `deploy-YYYYMMDD-name/database-before.tar`；未知名称、失败发布、硬链接和符号链接保留。
- 执行前重新核对清单、目录身份、文件身份和发布凭据，逐一核验最新保留副本 SHA-256；失败则不删除任何候选。
- 并发锁与逐项 fsync 审计记录删除意图/结果，执行前复核目录与标记。SHA-256 是文件一致性检查，不冒充数据库解密恢复验收。
- 不连接 Docker 或数据库，不扫描业务目录，不删除密钥、审计证据、截图、回滚镜像或业务卷。本轮未创建自动删除定时任务。

使用说明见 `docs/public/RELEASE_RETENTION.md`，发版备忘已补充容量收尾步骤。
