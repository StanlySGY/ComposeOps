## 已实现

1. 工具发现：初始意图目录缺少能力时，搜索中文任务词、工具名或分类；单次最多 5 项、单次执行最多追加 12 项和 24000 UTF-8 字节。搜索只在角色许可目录内，联网关闭时不发现网络工具，成员 Agent 不开放全局搜索；执行时仍有参数、授权、策略、审批和审计。状态在单次执行闭包内，未写入共享 Agent 或 MCP 注册表。
2. 预算结算：只接受非负安全整数，缺失分量或非法用量保留预留；重复完成通知不重复退款；总量与分量冲突时取较大值。失败的再次预留不会覆盖上一笔待结算数据。
3. 归档：启用时提前校验外置密钥、目录位置与 0700 权限；批次最多 100 条、约 8 MiB，单条超过 4 MiB 留源并提示。异步容量盘点最多检查 1000 项、缓存 30 秒，跳过符号链接；并发读取共享成功或可读失败状态。任务结果和未知副作用证据继续保留。
4. 界面：容量卡片、目录就绪状态、文件数/占用、剩余空间和采样时间；部分扫描明确标注；配置失效仍能暂停，初次读取失败可重试，空批次给出准确反馈。
