# 登录身份请求的取消与迟到响应隔离

日期：2026-11-29。基线 6aa7853，原工作区修改保持不动。

## 可复现问题

退出或收到会话失效通知后，尚未完成的 `/auth/status` 仍可能把旧管理员身份写回前端；登录后的确认还可能复用登录前的访客请求。身份缺失、角色不支持或账号停用的响应没有被完整校验，会进入空成员页面或保留旧身份。表单提交函数没有同步防重入，重复 submit 可以重复请求。

## 修复

身份读取以独立请求对象认领完成状态；失效、退出和重新登录中止旧读取并清理超时。旧请求的成功、失败和 finally 均不能覆盖新状态。登录固定身份代次，若其间会话失效便停止继续确认；登录 POST 成功后必须发起新的身份读取。

已登录响应需要有效 ID、受支持的角色及启用状态，并且不能同时要求初始化。无效或读取失败清空前端身份并显示连接重试；未登录响应不接受附带的 principal。登录表单在请求中拒绝重复提交。服务端会话、Cookie、项目权限和实际授权规则未改。
