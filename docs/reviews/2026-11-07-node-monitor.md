## 最终行为

- 节点页按非空分组排列状态卡，提供监控、服务、探测与分组操作。搜索/状态筛选写入 URL，返回后恢复。无数据以“—”呈现；探测失败与列表读取失败不会伪装成零容器。
- 节点列表请求、探测与切换/分组结果有时序隔离；同节点探测复用请求，错误操作恢复控件值。全局最近巡检评分明确标注范围；镜像检查明确覆盖全部可编辑项目。
- 监控将面板运行环境与所选 Docker 节点分组。环境指标默认收起，展开按钮带 aria-expanded；手机首屏优先露出容器搜索。顶部自动刷新有状态反馈，节点卡动作箭头轻微位移，尊重减少动态效果。
- 容器支持名称/镜像/节点搜索、CPU/内存/名称排序、指定容器空态和清除筛选；桌面表格在手机变成操作卡，不靠横向滚动寻找按钮。
- 日志入口携带可核验的项目、节点及容器身份；无纳管项目的行提供节点服务入口。历史入口定位同一容器；全部节点视图明确要求选节点，远端历史先显式进入该工作节点，防止静默读取本机数据。
- Docker 存储与容器查询采用同一 hostId；全部节点汇总显示缺失节点。超时会真正取消请求。最初三秒在真实机器的 118 个镜像环境误判，实测约四秒后调为十五秒，仍不阻塞已到达的容器数据。未知节点 404、不可达存储 503，给出中文重试提示。
- 预览夹具补齐真实 memUsage/memPercent/image/hostId 字段及分组模拟，不接真实 Docker。
