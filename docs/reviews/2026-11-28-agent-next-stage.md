## 边界与操作说明

成员只管理被授权项目的现有容器；不开放全局 AI、Shell、凭据、任意 Compose 编辑或创建容器。项目分组只整理显示，不代表访问权限。管理员之间共享全局运维数据；这不是 Docker 内核多租户隔离。

持久会话任务断线继续；服务重启后必须显式核对并继续。每会话一个活跃任务，全局最多四个，单次最长 30 分钟。未知副作用不重放，已提交的 Docker 操作可能无法撤销。模型本轮完成、后台操作完成与业务验收通过分别显示。15 分钟合成负载与少量真实模型案例不能证明无限期无人值守。

使用指南：[Agent 运维](../public/AGENT_OPERATIONS.md)、[成员与项目权限](../public/TEAM_ACCESS.md)。
