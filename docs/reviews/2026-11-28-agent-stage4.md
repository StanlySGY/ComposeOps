## 本轮变更

- 模型请求前预算预留，失败渠道同样占用；报告 usage 后结算，缺失 usage 按输入字节及输出上限保守估计；恢复任务沿用已累计预算。
- 工具回喂不再包含重复执行轨迹；工具结果保留首尾，上下文只裁剪完整旧工具轮次；自动摘要走确定性提取，避免隐藏的额外模型消耗。
- 成员 Agent 使用独立工具注册表，仅当前授权项目的状态、日志和现有容器启停。全局快照、记忆、Shell、配置编辑与创建容器不可用。会话/运行记录按所有者隔离；每步、审批及恢复重新核对账号版本与节点连接版本。
- 数据容量页显示 DB/WAL/可复用页/磁盘可用容量，与已有平台健康阈值告警配合。历史清理保护待恢复/未知结果任务。
- 每批最多 100 条已完成且超过 90 天的任务事件可加密归档；外置目录和密钥，写入并 fsync、解密核对后再删除精确事件 ID，任务结果与副作用证据保留；未完成任务不归档。默认关闭，生产配置后启用。
- 24–72 小时 soak 参数支持；长期观察必须按实际运行时长判定，不将启动观察误报为通过。
