# 数据库导出的生命周期（2026-11-29）

## 复现

导出成功后在 `dumping` 仍为 true 时调用关闭函数，函数直接返回，弹窗无法自动关闭。下载请求没有取消信号，读取响应体期间离开页面、切换节点或退出登录，迟到结果仍可下载旧数据库并显示成功。当前 401 也没有通知登录失效。

新增单测在旧实现下 5 项失败、1 项通过。浏览器首轮还发现目标容器的隐式可访问名称包含全部选项，现已为容器选择和库名输入提供明确名称；原失败记录保留。

## 修复

- 容器列表与导出请求传递 AbortSignal，固定弹窗打开时的认证世代，并在响应头、错误体和完整文件读取后检查归属。
- 页面失活、卸载、节点或认证变更时终止请求并清理监听，旧响应不下载文件、不显示提示、不使新会话退出。
- 成功下载先结束忙碌状态再关闭弹窗；对象 URL 在点击异常时也会释放。
- 读取容器失败可原位重试；导出失败保留容器与库名；导出期间锁定目标和关闭操作，避免重复提交。
- Redis 导出文案与实际 `redis-cli --rdb` 命令一致。

后端保持原来的导出语义：请求中断可以取消尚未完成的导出；完整备份验证后才提供下载。不涉及后台部署任务、不重放写请求，也没有改变生产数据。
