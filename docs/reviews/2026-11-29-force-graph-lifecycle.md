# 图谱缓存生命周期修复（2026-11-29）

## 问题和处理

服务拓扑与资产图谱共用的 ForceGraph 进入 KeepAlive 缓存后，原先仍会运行力导向动画、观察尺寸；拖动期间离开或卸载也会留下 window 指针监听。触摸取消、窗口失焦后再次抬手还可能触发旧节点点击。分层布局的单次取景帧此前没有记录和清理。

现在激活时只启动一组资源，失活与卸载时取消两类动画、断开 ResizeObserver、清理拖动和悬浮状态。迟到回调与隐藏时的数据变化不会重启动画或测量隐藏视口。切换为分层布局停止未冷却的物理循环，缓存返回保留用户缩放。pointercancel 和 blur 都会结束拖动，并移除残留的抬手监听。

核对 Vue 官方 KeepAlive 文档的缓存实例生命周期：失活并非卸载；onActivated 包含初次挂载，onDeactivated 也覆盖卸载，因此启动和清理均需幂等。本次没有引入新运行依赖。
