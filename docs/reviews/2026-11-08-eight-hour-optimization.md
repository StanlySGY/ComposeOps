- 新增 `scripts/volume-backup-service-integration.mjs`：独立数据库、唯一 Compose 项目、命名卷和归档目录，通过真实 scanner 与已注册的 ops 路由验证未纳管/未声明/不存在卷的拒绝、备份入库、下载 SHA256、一临时卷解包验证、完整覆盖恢复、隐藏文件/权限/符号链接恢复、损坏归档拒绝与删除。最后确认测试资源已清理，生产容器 ID 未变化。
- 远程下载代码路径使用真实 Docker helper，由测试内的传输适配接入本地 daemon，不暴露 Docker API。验证源卷不存在时仍可下载，且不自动创建该卷；不存在的归档明确失败。它不代表已验证真实异机 SSH/TCP 网络。
