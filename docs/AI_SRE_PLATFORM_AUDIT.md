## 明确边界

- 自动重启和可靠镜像变更当前面向单副本服务；多副本场景仍由管理员选择合适的运维流程。
- 镜像回退只恢复镜像，不能逆转数据库迁移、卷内容或外部依赖。配置快照保留展开后的环境变量，文件权限为 0600、目录为 0700，不经 API 或复盘返回。
- HTTP 验收只证明配置端点在观测窗口内达标。隔离恢复只证明归档可完整解包及清理，不证明数据库一致性或端到端业务恢复。
- AI 复盘以可控模型响应验证输出协议、已有证据引用、脱敏与失败处理；未调用外部模型评估真实推论质量。
