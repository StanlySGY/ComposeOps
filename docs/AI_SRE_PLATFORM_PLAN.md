## 交付范围

1. 应用可靠性目标：每个纳管应用可配置 HTTP 可用性探针、状态码/延迟要求、目标可用率和统计窗口。持久化样本与覆盖率、错误预算，失联/缺少数据不能记作成功。探针有超时、并发和响应体限制；配置变更隔离历史版本。
2. 有界自治：按节点、应用、服务、版本化流程显式授权；默认关闭。持续故障才可触发，具备有效期、次数预算、冷却时间、维护窗口和一键暂停。派发前再查策略、授权和目标身份；失败/结果不明禁止重放，自动审批来源可审计。
3. 可靠变更：评审后固定输入、目标服务与新旧镜像身份；升级前检查并保存恢复材料，执行后结合应用探针验收。失败时仅在事先授权且可验证条件下恢复原镜像；中断保留持久状态，不盲目重放。
4. 恢复演练：应用级备份覆盖与恢复目标；以隔离卷恢复验证归档内容，记录恢复用时、备份年龄、覆盖范围、结果和残留清理。支持可追踪的手动/定时演练；不能将解包成功描述为数据库业务可用。
5. 历史效果评估：从真实故障、处置、探针、变更和演练记录统计成功/失败/未知、恢复时间和复发情况，显示样本量与验证范围。AI 复盘引用证据，不自行扩大授权或改策略。
6. 产品与交付：中文桌面/手机 UI、总览与现有任务/日志/Agent 联动、持久化迁移、演示数据、错误与异步生命周期处理、公开文档、自动化回归、隔离真实 Docker 与浏览器演练、最终完整审查和本地提交。

## 执行边界

不对现有生产应用启用自动修复。产品提供显式配置授权入口，验证使用隔离测试项目。生产发版沿用已有独立流程，原有端口、加密卷、外置密钥、代理桥配置均保留。不得通过减少交付范围、跳过失败验证或仅添加入口链接来认定完成。
