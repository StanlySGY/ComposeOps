# 502 排查手册

1. 先确认访问入口对应的 Compose 项目和服务,再读取 `compose.ps`。
2. 检查入口服务是否运行、监听端口是否与 Compose 暴露端口一致。
3. 查看入口服务和上游服务的最近日志,按时间线对齐 502 出现时刻。
4. 检查上游健康状态、依赖服务和网络连接;不要仅凭单条日志下结论。
5. 给出最小修复建议和验证步骤。重启、改端口、改配置或执行容器命令前必须请求确认。

证据不足时明确标记不确定性,不要把常见原因写成已确认根因。
